- [t2v_prompts.json](t2v_prompts.json): 165 `{group, prompt}` records in the exact historical generation-jobs order: 72 `subject_consistency`, then 93 `overall_consistency`. The historical source is `wan22_t2v/vbench_nvfp4_main_7465c0f52_cfg43_officialneg_720p/jobs.json`. Only the absolute video paths were removed; prompts, punctuation, case, and ordering are unchanged. The prompt source was grouped from [official VBench metadata](https://github.com/Vchitect/VBench/blob/master/vbench/VBench_full_info.json). Do not sort or deduplicate this snapshot.
- [i2v_metadata.json](i2v_metadata.json): byte-for-byte copy of all 1,118 records from [official I2V metadata](https://github.com/Vchitect/VBench/blob/master/vbench2_beta_i2v/vbench2_i2v_full_info.json). Source and copied-file SHA-256: `8cf4d34dc11779a336c216a1a71d482927cfa24a1bf736ab5c92425609f129f8`.

The I2V metadata contains 246 `i2v_subject`, 109 `i2v_background`, and 763 `camera_motion` records. The recorded evaluation uses only the union of the first two subsets (355 prompt/image pairs), with official cropped 16:9 images. Obtain images from the [upstream I2V instructions](https://github.com/Vchitect/VBench/tree/master/vbench2_beta_i2v) and [official image download](https://drive.google.com/drive/folders/1fdOZKQ7HWZtgutCKKA7CMzOhMFUGv4Zx?usp=sharing), subject to their upstream terms.

These are historical input snapshots, not standard full-suite evaluations. T2V uses two selected prompt groups and five metrics on 165 videos per model. I2V uses one video per selected pair, not the standard five-sample full protocol; retaining all metadata does not mean all 1,118 inputs were evaluated. See [the recorded results](../results/README.md) for metric coverage.
